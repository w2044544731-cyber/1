# 今日清单

一个无需登录的中文待办网页，支持添加、勾选、删除和清除已完成事项。数据保存在当前浏览器的 localStorage，不会上传到服务器。

## 开发环境

需要 Node.js 22 或更高版本。没有第三方依赖，无需运行 npm install，也不需要数据库或密钥。

```sh
cd /workspace/1
npm start
```

默认监听 127.0.0.1:3000。可通过 PORT 和 HOST 覆盖；仅在确实需要外部访问时设置 HOST=0.0.0.0。

## 验证

```sh
npm run check
npm test
curl --fail http://127.0.0.1:3000/health
```

健康检查应返回 `{"status":"ok"}`。浏览器中可添加事项、勾选完成、刷新确认保存、删除事项。禁用浏览器存储时，页面会提示保存失败。

无需构建步骤；服务直接提供 public 目录中明确列出的静态资源。云环境发布后需要重新启动服务，运行中的进程不会随快照保留。
